# 🛍️ ShopZone – E-Commerce Web Application

ShopZone is a full-stack e-commerce web application developed using Java technologies. It provides a complete online shopping experience where customers can browse products, manage their cart and wishlist, place orders, and track purchases. The system also includes separate dashboards for administrators and delivery personnel to efficiently manage products, orders, customers, and deliveries.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/shah7205khushi/ShopZone-project.git
```

### Open Project

- Import the project into Eclipse IDE.
- Configure Apache Tomcat.
- Import the MySQL database.
- Update database credentials in `connection.java`.

### Run

Start Tomcat Server and open:

```
http://localhost:8080/template_2/
```
